# Schritt 99 – gewährte Aszendenzfunktionen

## Ergänzte Familien

- konkret gewährte Fertigkeiten
- konkret benannte gewährte Buffs
- zusätzliche Fertigkeitsplätze

Die Regeln erfassen ausschließlich eng begrenzte englische Originaltexte des
gepinnten offiziellen Baums. Eine Zeile wie `Grants Skill: ...` belegt damit,
dass ein Aszendenzknoten eine bestimmte Fertigkeit gewährt. Sie belegt ohne
weitere strukturierte Daten weder deren Schadenswerte noch Uptime, Kosten,
Triggerfrequenz oder DPS.

Beliebige Texte, die lediglich mit `Grants` beginnen, werden nicht als
gewährte Fertigkeit klassifiziert.

## Produktgrenze

Die neuen Tags sind Quellen-Evidenz für die spätere Verbindung von
Aszendenzplanung und Fertigkeitsmodell. Sie erzeugen bewusst keinen freien
Schadens-, Elementar-, Ressourcen- oder Rankingbonus.
